# Instruction

You will receive raw notes from a 1:1 conversation. Rewrite them as a complete
record using the sections below. If a section has no content in the source,
write "(none)"; do not invent.

## Participants

Two people. Name + role/team if inferable.

## Topics

One `###` subsection per topic that actually came up — not what was scheduled.
Inside each, record the full exchange: what each person said, concerns raised,
context given. Quote distinctive phrases verbatim. No length limit; every
point in the source must land in exactly one topic.

## Decisions

Bullet list of any decisions made. Write "(none)" if pure conversation.

## Action items

- [ ] task — Owner (due date if mentioned)

## Watch items

Things that are not yet decisions but should be revisited. Concerns, risks,
or proposals that need follow-up.

## Interpretation

_Model inference — not stated in the source._

The emotional or relational signal of the conversation, and anything implied
but left unsaid. Helpful when reviewing the relationship over time; keep it
clearly separate from the factual record above.
